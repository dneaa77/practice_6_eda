# Практическая работа №6
## Предобработка текста и классификация SMS

### Цель работы

Разработать собственный пайплайн предобработки текстовых данных, преобразовать текст в числовые признаки с помощью TF-IDF и обучить модель машинного обучения для классификации сообщений.

### Датасет

Использован набор данных SMS Spam Collection из UCI Machine Learning Repository. Он содержит SMS-сообщения двух классов: `ham` — обычные сообщения и `spam` — спам.

Источник: https://archive.ics.uci.edu/dataset/228/sms+spam+collection

### Выполненные этапы

1. Загружен и изучен датасет.
2. Реализована функция очистки текста: приведение к нижнему регистру, удаление пунктуации и цифр, удаление стоп-слов.
3. Выполнена токенизация текста.
4. Применено преобразование TF-IDF с параметрами `min_df=2` и `max_df=0.95`.
5. Данные разделены на обучающую и тестовую выборки в соотношении 80/20.
6. Обучен классификатор логистической регрессии.
7. Качество модели оценено с помощью Accuracy, Precision, Recall, F1-score и матрицы ошибок.
8. Проанализированы ошибки классификации.

### Анализ ошибок

Были рассмотрены ошибочно классифицированные сообщения. Возможные причины ошибок: сходство спама с обычными сообщениями, рекламные слова в обычной переписке, сокращения и недостаток контекста.

Для каждого найденного ошибочного предсказания сформулирована отдельная гипотеза на основе содержания сообщения.

### Вывод

В ходе работы реализован пайплайн обработки текстовых данных и классификации SMS. Текст был очищен и токенизирован, затем преобразован в числовые признаки с помощью TF-IDF. На этих признаках обучена логистическая регрессия.

Качество классификации оценено на тестовой выборке. Анализ ошибок позволил определить возможные причины неправильных предсказаний и ограничения выбранного подхода.
